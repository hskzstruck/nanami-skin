# +Nanami

아리하라 나나미 피규어의 **캐릭터 색상**을 바탕으로 만든 VS Code 다크 색상 테마입니다.

- 편집기 배경: `#1F1E23`
- 나머지 기본 UI 배경: `#27262D`, 왼쪽 아이콘 바: `#BF4C6E`
- 선택한 아이콘 뒤 배경: `#994D3A`, 비활성 아이콘: `#F9E3DE`
- 활성 탭: 더 진한 색과 아래쪽 금색 선
- 함수 이름: `#D64845`; 괄호 단계: `#DEC095`, `#DFC58A`, `#D26446`
- 강조색: 머리의 금색, 눈의 붉은 갈색, 머리끈과 옷 테두리의 빨간색, 옷의 흰색
- 같은 계열 안에서 밝기와 채도를 조금씩 달리해 영역과 문법을 구분합니다.
- 사진 배경과 피규어 받침대 색상은 사용하지 않습니다.

## 미리 보기

이 폴더를 VS Code에서 연 뒤 `F5`로 확장 개발 호스트를 실행합니다. 새로 열린 **확장 개발 호스트 창에서** `Ctrl+K`, `Ctrl+T`를 눌러 `+Nanami`를 선택합니다. 탐색기에서 `package.json`이나 `themes/plus-nanami-color-theme.json`을 열면 코드 글자색을 확인할 수 있습니다. 시작 페이지의 링크는 코드 문법 색과 별도로 지정됩니다.

색상만 변경하는 테마이며 아이콘, 글꼴, 배경 이미지는 포함하지 않습니다.

## 다른 기기에 설치

`plus-nanami-theme-0.0.1.vsix` 파일을 내려받은 뒤, VS Code 확장 보기의 `...` 메뉴에서 **VSIX에서 설치**를 선택합니다. 설치 후 색상 테마 목록에서 `+Nanami`를 선택합니다.
